# Work 4 Master Spec

## 프로젝트 주제

**컴퓨터가 데이터를 기억하는 방식: NAND Flash의 동작 원리**

Work 4는 NAND Flash의 구조와 동작 원리를 웹 환경에서 시각적으로 탐색하고 이해하는 인터랙티브 설명 자료다. 단순한 아티클이나 슬라이드가 아니라, 스크롤 기반의 축척 이동, 애니메이션, hover/click 인터랙션, 개념 시뮬레이션을 활용해 사용자가 직접 내부 구조와 동작을 따라가며 이해하도록 구성한다.

## 기본 방향

- 웹이라는 매체의 장점을 적극 활용한다.
- 줄글보다 시각적 이해를 우선한다.
- 스크롤을 통해 SSD → NAND Package → Die → Block → Page → Cell처럼 더 작은 축척으로 들어가고 나오는 경험을 만든다.
- 각 축척에서는 현재 보고 있는 구조 하나가 화면의 주인공이 되도록 한다.
- 장면 전환은 단순 페이지 교체가 아니라 scale, opacity, clip, blur, layer transition 등을 조합해 자연스럽게 이어지도록 설계한다.
- 핵심 공학 구조는 과도한 실사 렌더링보다 단순화된 2D/2.5D/3D 개념도와 인포그래픽 스타일을 우선한다.
- hover 시 추가 설명, click/toggle 기반 비교, 간단한 시뮬레이션 등 사용자의 직접 조작을 적극 활용한다.
- 본편은 시각적 직관과 인터랙션에 집중하고, 상세한 학습용 설명은 후반 Article/부록 영역에서 보강한다.

## 언어 규칙

- **사용자에게 보이는 기본 설명 문구는 모두 한글로 작성한다.**
- 제목, 본문, tooltip, 말풍선, 안내 문구, 버튼 설명, 장면 해설 등 일반 설명은 한글을 기본으로 한다.
- 기술적으로 통용되는 고유 용어나 약어는 영어 표기를 유지한다.
  - 예: `NAND Flash`, `SSD`, `Die`, `Plane`, `Block`, `Page`, `Cell`, `Program`, `Read`, `Erase`, `FTL`, `Garbage Collection`, `Wear Leveling`, `ECC`, `LBA`, `PPA`, `Vth`
- 영어 기술 용어가 처음 등장할 때 필요한 경우에만 한글 설명을 짧게 덧붙인다.
- 장식 목적의 불필요한 영어 카피는 사용하지 않는다.
- 시각 디자인을 위해 영어 문장을 넣기보다, 의미 전달이 필요한 모든 텍스트는 우선 한글로 작성한다.

## 현재 디자인 레퍼런스 방향

- Seeing Theory: 단순한 도형과 직접 조작 중심의 인터랙티브 설명 방식
- Bartosz Ciechanowski: 공학 구조를 단계적으로 분해하고 움직임으로 이해시키는 방식
- The Pudding: sticky graphic / scrollytelling 기반의 장면 전환 구조
- Nicky Case / Explorable Explanations: 사용자가 직접 조작하며 개념을 발견하는 방식

이 문서는 Work 4 설계가 구체화되는 과정에서 Scene 구조, 콘텐츠 흐름, 비주얼 시스템, 인터랙션 규칙을 계속 추가하는 기준 문서로 사용한다.
