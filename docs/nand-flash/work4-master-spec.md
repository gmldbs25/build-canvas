# Work 4 Master Spec

## 프로젝트 주제

**컴퓨터가 데이터를 기억하는 방식: NAND Flash의 동작 원리**

Work 4는 NAND Flash의 구조와 동작 원리를 웹 환경에서 시각적으로 탐색하고 이해하는 인터랙티브 설명 자료다. 단순한 아티클이나 슬라이드가 아니라, 스크롤 기반의 축척 이동, 애니메이션, hover/click 인터랙션, 개념 시뮬레이션을 활용해 사용자가 직접 내부 구조와 동작을 따라가며 이해하도록 구성한다.

## 기본 방향

- 웹이라는 매체의 장점을 적극 활용한다.
- 줄글보다 시각적 이해를 우선한다.
- 스크롤을 통해 SSD → NAND Package → Die → Block → Page → Cell처럼 더 작은 축척으로 들어가고 나오는 경험을 만든다.
- 각 축척에서는 현재 보고 있는 구조 하나가 화면의 주인공이 되도록 한다.
- 장면 전환은 단순 페이지 교체가 아니라 scale, opacity, clip, blur, layer transition 등을 조합해 자연스럽게 이어지도록 설계한다.
- 핵심 공학 구조는 과도한 실사 렌더링보다 단순화된 2D/2.5D/3D 개념도와 인포그래픽 스타일을 우선한다.
- hover 시 추가 설명, click/toggle 기반 비교, 간단한 시뮬레이션 등 사용자의 직접 조작을 적극 활용한다.
- 본편은 시각적 직관과 인터랙션에 집중하고, 상세한 학습용 설명은 후반 Article/부록 영역에서 보강한다.

## 언어 규칙

- **사용자에게 보이는 기본 설명 문구는 모두 한글로 작성한다.**
- 제목, 본문, tooltip, 말풍선, 안내 문구, 버튼 설명, 장면 해설 등 일반 설명은 한글을 기본으로 한다.
- 기술적으로 통용되는 고유 용어나 약어는 영어 표기를 유지한다.
  - 예: `NAND Flash`, `SSD`, `Die`, `Plane`, `Block`, `Page`, `Cell`, `Program`, `Read`, `Erase`, `FTL`, `Garbage Collection`, `Wear Leveling`, `ECC`, `LBA`, `PPA`, `Vth`
- 영어 기술 용어가 처음 등장할 때 필요한 경우에만 한글 설명을 짧게 덧붙인다.
- 장식 목적의 불필요한 영어 카피는 사용하지 않는다.
- 시각 디자인을 위해 영어 문장을 넣기보다, 의미 전달이 필요한 모든 텍스트는 우선 한글로 작성한다.

## 현재 디자인 레퍼런스 방향

- Seeing Theory: 단순한 도형과 직접 조작 중심의 인터랙티브 설명 방식
- Bartosz Ciechanowski: 공학 구조를 단계적으로 분해하고 움직임으로 이해시키는 방식
- The Pudding: sticky graphic / scrollytelling 기반의 장면 전환 구조
- Nicky Case / Explorable Explanations: 사용자가 직접 조작하며 개념을 발견하는 방식

## 1차 비주얼 기준안

현재까지 만든 시안 중 **마지막 인포그래픽형 NAND Package 장면**을 Work 4 전체 비주얼의 1차 기준안으로 사용한다. 이후 Scene별 시안은 이 분위기와 구조를 기본값으로 삼고, 필요할 때만 장면 특성에 맞게 변형한다.

### 화면 구성 원칙

- 전체적으로 짙고 차분한 다크 배경을 사용하되, 배경 자체가 시선을 끌지 않도록 한다.
- 화면의 중심에는 현재 축척에서 설명할 공학 오브젝트 하나를 크게 배치한다.
- 오브젝트는 실사 사진이나 영화적인 고광택 렌더가 아니라, **단순화된 2.5D 공학 개념도 / 인포그래픽** 스타일로 표현한다.
- 입체감은 구조와 계층을 이해하는 데 필요한 수준만 사용하며, 과도한 반사·광원·파티클·네온 효과는 지양한다.
- 모서리, 면, 그림자, 색 분리는 정돈되고 약간 친근한 인상을 주되 캐릭터화하거나 장난감처럼 표현하지 않는다.
- 화면에는 충분한 여백을 두고 한 장면에서 전달하는 핵심 개념을 제한한다.
- 텍스트 설명은 짧고 보조적으로 사용하며, 시각 자료보다 먼저 시선을 가져가지 않도록 한다.
- hover/click이 가능한 구조는 평상시에는 화면을 복잡하게 만들지 않고, 사용자의 행동에 따라 tooltip이나 보조 설명이 나타나게 한다.

### 색과 강조

- 기본 구조는 저채도의 회색·청회색 계열을 사용한다.
- 현재 설명 중인 구조나 데이터 흐름에만 제한적으로 포인트 컬러를 사용한다.
- 포인트 컬러는 cyan/blue 계열을 우선 검토하되, Scene별 의미 구분이 필요한 경우 보조 색을 추가할 수 있다.
- 색은 장식보다 상태·계층·선택·데이터 흐름을 구분하기 위한 정보 표현 수단으로 사용한다.

### 스크롤 장면과의 결합

- 시안은 항상 완성된 포스터가 아니라 **실제 웹 viewport에서 특정 scroll progress에 멈춘 한 프레임**으로 설계한다.
- 이전 축척의 오브젝트와 다음 축척의 오브젝트가 전환 구간에서 일시적으로 공존할 수 있지만, 현재 주인공은 명확해야 한다.
- 스크롤에 따라 오브젝트가 확대되고 화면 밖으로 밀려나거나, 내부 구조가 나타나거나, 특정 레이어가 투명해지는 방식으로 다음 축척에 진입한다.
- `SSD → NAND Package → Die → Block → Page → Cell` 이동은 서로 분리된 페이지처럼 느껴지지 않고, 하나의 연속된 탐험처럼 느껴지도록 한다.
- 필요하면 화면 상단이나 측면에 현재 축척/계층을 알려주는 작고 단순한 indicator를 유지한다.

### 피해야 할 방향

- 실제 제품 광고처럼 보이는 실사 SSD/NAND 렌더
- 영화 포스터처럼 강한 조명과 극적인 원근감
- 한 화면에 SSD, Package, Die, Block, Page, Cell을 모두 전시하는 구조
- 설명 텍스트와 라벨을 과도하게 배치한 기술 자료형 화면
- 의미 없는 배경 파티클, 회로선, 장식용 네온 효과
- 실제 웹 구현보다 한 장의 완성 이미지 자체가 더 중요한 컨셉 아트 방식

이 비주얼 기준안은 향후 Scene 시안 제작과 실제 구현 검토 과정에서 계속 수정할 수 있으나, 별도의 합의가 있기 전까지 Work 4의 기본 디자인 방향으로 유지한다.

이 문서는 Work 4 설계가 구체화되는 과정에서 Scene 구조, 콘텐츠 흐름, 비주얼 시스템, 인터랙션 규칙을 계속 추가하는 기준 문서로 사용한다.
