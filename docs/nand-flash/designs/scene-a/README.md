# Work4 · Scene A 디자인 초안

1920 × 1080 데스크톱 화면에서 SSD 전체를 바라보는 한 프레임입니다. `index.html`을 브라우저에서 열면 창 크기에 맞춰 시안 전체가 비례 축소됩니다. 모바일 레이아웃을 설계한 것은 아닙니다.

## 결과물

- `scene-a-1920x1080.png`: 실제 Chrome에서 정적 시안을 렌더링한 검토용 원본 캡처.
- `index.html`: 제목, 계층 표시, 고정된 hover 툴팁, 축척 표시, 스크롤 안내를 각각 분리한 정적 화면.
- `scene-a.css`: Scene A에 한정된 색상, 여백, 타이포그래피.
- `ssd-board.svg`: 기판, Controller, NAND Package, 연결 패턴을 분리한 벡터 오브젝트.

## 기준 자료

`origin/main`의 `073f115` 버전에 있는 아래 두 자료를 먼저 읽고 이미지를 직접 확인했습니다. 작업 시작 당시 로컬 checkout에는 해당 자료가 없어 원격 Git 객체에서 읽었습니다. 기존 Work를 포함한 로컬 checkout은 갱신하지 않았습니다.

- `docs/nand-flash/work4-master-spec.md`
- `docs/nand-flash/references/work4-visual-reference-01.webp`

기준 이미지의 짙은 청회색 배경, 여백, 얕은 입체감, 차분한 면 분할을 계승했습니다. Scene A의 주인공은 SSD 하나입니다. 하위 구조를 나열하지 않고 다음에 진입할 NAND Package 하나만 청색 면과 얇은 테두리로 구분합니다. 실제 제품과 치수를 재현한 도면이 아닌 설명용 개념도입니다.

## 화면과 이후 전환

- 왼쪽: 한글 제목, 부제, 두 줄 설명.
- 중앙 오른쪽: SSD 기판, Controller 하나, NAND Package 세 개.
- 상단: SSD가 활성화된 작은 계층 표시.
- 오른쪽: cm 영역에 표시된 축척 위치. 현재 눈금은 단계 안내용이며 정밀한 로그 축이 아닙니다.
- 하단: 스크롤 안내와 다음 목적지 NAND Package.
- 툴팁: NAND Package에 hover한 상태를 고정하여 표현했습니다. 실제 hover 동작은 이 단계에 포함하지 않습니다.

향후 구현 시 `ssd-camera`를 확대·이동하는 부모 그룹으로 사용하고 `nand-target`을 확대 목적지로 사용합니다. 현재 대상 중심은 1920 × 1080 캔버스 기준 약 `(1347, 517)`입니다. 다음 축척에서는 이 지점을 화면 중심으로 이동시키고, PCB·Controller·다른 Package의 가시성을 개별 조절할 수 있습니다. 제목과 안내 UI는 오브젝트와 독립된 HTML 요소입니다. 실제 통합에서는 SVG를 인라인으로 옮겨 그룹별로 제어할 수 있습니다.

## 검토

Chrome의 1920 × 1080 캡처를 직접 확인했습니다. 한글 글리프, 두 줄 설명, 제목과 SSD의 분리, 툴팁과 강조 Package 연결, 화면 잘림 여부를 검토했습니다. 시각 자료만으로 NAND Package가 다음 목적지임을 보여주며 과도한 glow·입자·광택은 사용하지 않았습니다.

이번 변경은 이 디자인 폴더만 추가합니다. 기존 Work, 홈 목록, 라우트, 빌드·배포 설정은 변경하지 않았습니다. Scene B 이후, 실제 스크롤 애니메이션, simulation, 페이지 배포는 포함하지 않습니다.
