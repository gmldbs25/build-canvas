# Work 08 V2 — 25개 인터랙션 구현 명세

기준: MANUSCRIPT-01-07.md, MANUSCRIPT-08-12.md. 각 ID는 해당 장의 실험 위치에 연결된다. 실험은 '질문 → 예측 → 조작 → 관측 → 해석 → 한계'를 갖는다. 사용자가 직접 조작하기 전에 설명이 보이고, 조작 후 결과와 해석이 같은 화면에 남는다. 자동 진행은 선택 사항이다. 수치 출력과 그래프는 동일 계산 결과를 공유한다. 값은 표시 단계에서만 반올림한다.

## 공통 계약
- 결과 분류: exact-integer(정수 정확 계산), numeric(실수/복소 수치 근사), truncated(유한 절단), model(가상 모형), replay(검증된 기록 재현), reference(출처가 명시된 데이터). ψ의 항 집합은 정확하지만 로그 합은 수치값이다.
- 각 실험: id, 질문, 안내, 기본 상태, 입력 범위·단위·유효성, 출력·축, 데이터 출처, 계산 함수, 해석, 제한, reset, keyboard, 접근성 대체 텍스트, fixtures, URL 파라미터 검증.
- 범위 밖은 명시적으로 거부하거나 더 좁은 지원 범위를 안내한다. NaN/Infinity를 정상 수치처럼 표시하지 않는다. 입력이 큰 계산은 worker로 넘기고 이전 요청은 취소 또는 무시한다.
- π(1)=θ(1)=ψ(1)=0. ψ₀(x)=ψ(x)−Λ(x)/2(정수 소수 거듭제곱에서만). 모든 계산은 자연로그. π(x)와 원주율은 문맥에서 구분. Li₂와 li의 정의는 본문에 따른다.
- graph: 색+선 스타일+직접 라벨, 축과 단위, 로그축 표기, 터치/키보드로 읽을 수 있는 값. 고정 비교 눈금이 필요할 때 명시하며 클리핑 시 경고 또는 자동 범위. 읽기 표와 수치 요약 제공. SVG는 단순 도식, Canvas는 밀도 높은 실시간 플롯, 수식은 로컬 번들 렌더러.
- 학습 상태만 localStorage(versioned)로 저장; 실험 state는 필요한 경우만 저장. 개인정보/계정/외부 분석 API 불필요. 다른 Work의 키 및 CSS에 영향 금지.
- 모든 실험은 JS 없을 때 개념 설명과 대표 수치/정적 그림을 남긴다. 모바일에서 그래프와 조작부가 멀리 떨어지지 않게 한다.

## 01-A 자연수 분해기 (exact-integer)
질문: 다른 분해 순서는 다른 결과를 만드는가?
입력 n=2…1,000,000 정수(default 3600), 분해할 합성수 노드와 유효 약수 선택. 약수 목록은 실제 계산; 예제 n=12,84,3600. 출력: 곱셈 트리, 현재 잎의 곱, 완성된 p^k 지수표. 두 경로를 나란히 보이고 잎의 곱=n 불변식을 유지. 사용자에게 합성수 잎이 남았음을 표시하고 완성 후 유일성 설명. 잘못된 약수는 거부·이유 안내. trial division up to √n, Number 안전 범위에서만. 검수: 84→2²·3·7; 3600→2⁴·3²·5²; 2와 999983은 잎 하나; 1, 음수, 분수, 범위 초과 거부.

## 01-B 소수 발굴 실험 (exact-integer)
입력 N=30/100/200/400(default 100), 단계별 다음 소수/되돌리기/초기화. p=2부터 p²≤N 동안 p², p²+p,… 제거, 처음 지운 원인 보존. 격자 1은 제외, p 자체는 보존. 남은 개수/현재 p/다음 제거 후보. 학습: 49가 p=7에서 사라짐, √N까지만 필요. 검수: N=100→25개, 1은 소수 아님, N=400의 최종 집합은 독립 체와 일치; 모바일 격자 클릭 강제 없음, 키보드 버튼으로 모든 진행.

## 02-A Prime Microscope (exact-integer)
입력 정수 구간 시작 a≥1, 길이 20…2000, 끝≤10⁶; default [1,100], 프리셋 [999900,1000000](101개). 두 비교 패널의 폭이 다르면 표시, 같은 폭 비교 프리셋도 제공. 체 및 이진 탐색으로 구간 내부 소수 표시. 소수 수, first/last, 완전한 내부 간격 평균/최대, 정수 개수 대비 밀도. 빈 구간 또는 소수 하나면 gap 통계 없음. 검수: [1,100] 25개, [999900,1000000] 8개, [14,16] 빈 구간. 소수의 실제 위치를 픽셀 크기에 따라 누락하지 않는다.

## 02-B Ulam Spiral (exact-integer)
입력 홀수 격자 11…201(default 51), 기본 중앙 1, 2는 오른쪽, 3은 위, 시계 반대 방향. 열/행 좌표를 명시. 선택한 대각선의 n 목록과 소수 수, 전체 격자 밀도. Canvas에 실제 체 결과, 키보드 방향키나 좌표 입력으로 선택. 검수: 1=(0,0),2=(1,0),3=(1,1),9=(1,−1) (y가 위쪽 양수), (201²)까지 전단사; 크기 변경 시 같은 좌표 값 보존. 유한 대각선은 소수 무한성의 증명 아님.

## 02-C Prime Gap Explorer (exact-integer)
입력 구간 [a,b] within [1,10⁶], default [2,10000], 프리셋 폭 동일 구간 및 [2,10⁶]. 연속 소수 간격 g=p_next−p; 두 끝 모두 구간 내부일 때만 포함. 히스토그램(개수/비율 전환), 평균, median, 최대, 표본 수. 기대 밀도 ln(midpoint)은 참고선이지 특정 간격의 예측이 아님. 검수: [2,13] 간격 1,2,2,4,2; 2 이후 홀수 간격 없음; 모든 막대 빈도 합=gap 개수.

## 03-A Prime Counting Laboratory (exact-integer + numeric)
입력 xmax=10…10⁶ 로그 슬라이더, 샘플 x=정수 또는 실수, 선 토글 π, x/ln x, Li₂, 표준 li(심화), 선형/로그 x축. 출력 π는 실제 점프, 근사 곡선과 수치 비교. 큰 범위는 모든 점프를 동일 화면 픽셀로 그릴 필요 없으나 단순화 방법을 표시, 확대 시 정확한 구간. li는 정적 기준값 및 검증된 적분/급수 구현, Li₂(2)=0, x>1에서만 근사 활성. 검수: π(100)=25, π(10⁶)=78498, Li₂(100)=29.08097780396214. 그래프 x=2에서 Li₂=0이므로 로그 y축이면 표시하지 않거나 선형 y 유지.

## 03-B Error Explorer (numeric)
03-A와 동일 core, 독립 state 또는 명확한 상태 연동. 선택 근사 f와 E=π−f, |E|, E/π, π/f를 탭으로 비교. 분모 0이면 N/A. 기본 x 10…10⁶, 오차 그래프 zero line 및 단위. 100과 10⁶에서 상대·절대오차가 다른 경향을 보여 줌. 검수: π(10)=4, f=10/ln10≈4.3429448, signed error≈−0.3429448. Li₂(2)=0일 때 ratio N/A. 상대오차 부호를 뒤집지 않는다.

## 04-A Complex Playground (numeric)
입력 두 복소수 a,b∈[−3,3]+i[−3,3], 기본 1+i와 i, 덧셈/곱셈/켤레 선택. 출력 벡터·복소식·절댓값·편각(라디안 및 도), 결과가 영역 밖이면 축 확장. 정확한 수식 a+bi, (a+bi)(c+di)=(ac−bd)+(ad+bc)i. 편각 atan2, zero는 정의하지 않음. 검수: (1+i)i=−1+i, |3+4i|=5, z·0=0. 입력 키보드 숫자·터치 포인트 동시 지원.

## 04-B Euler Wave Laboratory (numeric)
입력 θ∈[0,2π] 또는 [0,360°], ω∈[0.5,4] rad/u, 재생·일시정지·한 단계. 출력 단위원 회전, cos와 sin, 동기 커서, x^σ exp(iγln x) 예고 탭(u=ln x). 시간/각도/각주파수 구분. 기본 자동 재생 안 함, 모션 감소에서 단계 조작. 검수: π/2→(0,1), π→(−1,0), 2π→(1,0), γ=10일 때 2π/10. 그래프 선과 회전점이 동일한 theta를 사용.

## 05-A Infinite Sum Laboratory (truncated + numeric)
입력 real s=0.25…4(default 2), N=10…10000(로그 눈금), 프리셋 0.5/1/1.5/2. 출력 S_k(1≤k≤N), 항 크기, S_N, 수렴 상태(이론적), s>1에서만 ζ(s) 기준과 절단 tail 범위: (N+1)^(1−s)/(s−1) ≤ Σ_{n>N} n^(−s) ≤ N^(1−s)/(s−1). s≤1에서 ζ의 일반 급수 값으로 표기 금지. N 또는 s 전환 시 축 비교가 가능하도록 고정/자동 선택. 검수: s=2,N=10 S_N≈1.54976773116654, s=1,N=10=2.92896825396825. s=1은 발산으로 표기.

## 05-B Euler Product Builder (truncated)
입력 s=1.1…4(default 2), 처음 K=0…20개 소수, 표 n≤120(기본 60). 유한 곱 P_K=∏_{j≤K}(1−p_j^(−s))^(−1); 항 표는 모든 소인수가 선택 집합에 있는 n의 역 s제곱만 표시. 유한 곱 자체는 선택 소수의 거듭제곱을 무한히 포함하므로 표의 유한 합과 같지 않다. log1p 활용, K=0의 곱=1. 검수: p=2,3 선택 시 12/18 등장, 5/10 누락; 2,3,5 선택 시 10 등장. 두 항의 중복 생성 금지.

## 06-A Beyond the Convergence Circle (truncated + numeric)
입력 z∈[−2,2]², N=1…50(항 개수로 정의), 기본 0.5. S_N=Σ_{k=0}^{N−1}z^k; F=1/(1−z). 단위원, 복소 입력점, 부분합 궤적과 F를 별개 출력 평면에. |z|<1 / ≥1 분류; z=1에서는 F=극, S_N=N; 큰 궤적은 자동 축 또는 표시 범위 경고. 검수: z=−1 부분합 1과 0 교대, F=.5; z=2,N=4 S_N=15,F=−1. z=0.5,N=10 S_N=1.998046875.

## 06-B Zeta Continuation Laboratory (numeric + truncated)
입력 real s∈[−2,3], N=10…10000, s=1 pole, default .5. 출력 ζ(s) 수치 및 원래 부분합, 수렴 가능한 영역 표시, s=1 양쪽 그래프 선 분리. 실수 ζ 기준 ζ(−2)=0, ζ(−1)=−1/12, ζ(0)=−.5, ζ(.5)≈−1.46035450880959, ζ(2)=1.64493406684823. core 수치 알고리즘은 NUMERICS.md를 참고. raw eta 나눗셈만으로 구현하지 않음. 실제 zeta domain과 UI 평가 범위는 구분한다.

## 07-A Zeta Explorer (numeric)
입력 s=σ+it, σ∈[−2,3], |t|≤80; initial .5+14i. 출력 복소 입력점, ζ(s) 복소 출력점과 크기/편각, 수치 오차 범위와 상태. Domain coloring 타일은 계산된 ζ값을 사용, phase 색상과 magnitude 밝기의 범례, pole mask. 고비용 전체 heatmap은 worker·타일 캐시·요청 토큰, 초기에는 임계 띠 중심으로 96×160 정도, 확대 해상도는 측정 기반. 수치적으로 작은 값은 near zero이지 증명된 영점 아님. 데이터 마커와 직접 평가 결과를 구분. |s−1|<10⁻⁶은 pole-near 상태로 안내(정확히 1만 pole). 검수: s=1+2πi/ln2는 유한하고, 켤레 대칭, 근접 영점 residual, −2 자명 영점. 열 지도의 색을 수치 대신 사용할 수 없음.

## 07-B Zero Hunter (numeric + reference)
입력 t∈[0,80] 로그 아님, step .01(정밀 입력), 선택 확대 ±.2 및 첫 알려진 영점 snap. |ζ(.5+it)| 선, real/imag 탭, 후보 근처 수치. 단순 국소 최소는 후보라는 표시. 첫 60개 데이터 중 평가 범위 안만 실제 ζ 평가와 연동; t>80 데이터는 reference-only로 구분. Hardy Z 부호 변화는 심화 옵션, 정확한 theta 계산과 검증 필요. 전체 임계 띠 영점 완전성을 주장하지 않는다. 검수: 첫 세 영점 위치, t=14에서 |ζ|≈.1056; 알려진 좌표 근처 magnitude<1e−8, s=0.5+50i는 0 아님.

## 07-C Symmetry Laboratory (model)
입력 β∈[.05,.95], γ∈[5,80], default .3,14. 출력 가상 점 β±iγ 및 1−β±iγ(중복 제거), 실수축·임계선 대칭. 실제 알려진 영점 모드와 시각적·문구상 분리. 네 점은 제타 함수 영점이라는 가정의 결과이지 실제 ζ 평가 아님. 검수: β=.3→.3,.7 각 ±γ; β=.5에서 두 점만; γ는 양수. RH 결론을 대칭만으로 얻는다는 해석 금지.

## 08-A Counting Function Laboratory (exact-integer + numeric)
입력 x=1…10⁴, 기본 10, 정수/실수 입력 및 x 최대 범위; 실제 소수 목록과 prime power 이벤트. π,θ,ψ 계단, 점프의 Λ(n), x에서 세 값. θ/ψ의 로그 단위와 π 개수 구분. 검수: ψ(5)=ln60, ψ(10)=ln2520, θ(10)=ln210, ψ(4)−θ(4)=ln2, ψ(5.5)=ψ(5). 6에서는 ψ 점프 없음.

## 08-B Prime Power & LCM Builder (exact-integer + numeric)
입력 m=1…50, default 5. 소수별 최대 지수 e_p=max{k:p^k≤m}, LCM=∏p^e (BigInt), log=Σ e_p ln p. 단계별 변경 지수 및 새로운 배율. 검수: LCM(1..5)=60, (1..10)=2520, 6에서는 변화 없음; 8→ln2 증가, 9→ln3 증가. 큰 값은 BigInt 문자열로 표시, Math.log(BigInt) 금지.

## 08-C Log Derivative Explorer (truncated)
입력 real s∈[1.1,4], p 목록 2,3,5,7, K=1…6, default 2,K=3. 각 항 z=p^(−ks), log term z/k, negative derivative term ln p·z. 표·수식 하이라이트, 유한 합과 선택 인자의 정확한 로그미분 Σp ln p/(p^s−1) 비교, 차이는 k 절단. 검수: p=2,k=3,s=2→ln2/64. K가 증가하면 양수 실수 조건에서 합 증가 및 유한 인자의 값에 접근. 전체 ζ의 로그미분과 유한 곱의 로그미분을 구별.

## 09-A Prime Wave Laboratory (exact events + truncated)
대표 품질 기준. 입력 N∈[0,60], 프리셋 0,1,3,15,30,60, x window 기본 [2,100], 범위 [2,1000] 내 zoom/pan; 기본 15, evaluation x=5.5/100 등. 데이터는 60개 positive γ, β=.5 고정, 전부 conjugate pairs. ψ₀(x) 참조와 오른쪽 연속 ψ를 토글 또는 점프 midpoint marker로 구분. B(x)=x−ln(2π)−.5log1p(−x^−2); W_j(x)=−2x^.5(.5cos(γ_j ln x)+γ_j sin(γ_j ln x))/(.25+γ_j²); F_N=B+ΣW.
출력 1: 실제 계단/주항 x/밑그림 B/절단 근사, 2: ψ−x 및 F_N−x 잔차, 3: F_N−ψ₀ 근사 오차, 4: 선택 영점의 진폭, 로그 주기, 위상, signed contribution, 5: 기여 스펙트럼(양/음), 6: RMSE 및 max absolute error. 선택한 영점은 포함된 N 범위 내 유지. N=0에서 파동 선택 N/A. RMSE 기본 비교는 균일한 x sample grid(고정 0.25 간격 또는 명시적 동일 sample count)와 ψ₀, 점프점에서 반쪽 값. 점프 제외 모드도 가능하지만 범위·샘플 수·규약 명시. 기존 RMS와 비교할 때 오른쪽 연속 기준이었다는 점을 구별.
시각: 화면 폭에 따라 u=ln x 축 또는 x축, 그래프별 축 직접 라벨, 차트 tooltip 및 keyboard x step. 파동을 충분히 샘플링: u 방향 Δu≤2π/(16γ_max) 또는 적응 샘플, sample budget 넘으면 확대 요청. 1000까지의 실제 계단은 공용 core 사용, 오래된 1000 제한 로직을 조용히 초과하지 않는다.
검수: NUMERICS의 20개 기준값; ψ₀(4)=2.1383330595, F60(4)≈2.14768467835; F0(5.5)≈3.678931239, F60(5.5)≈4.1184984; N=3보다 1이 일부 지점에서 가까울 수 있다; 근사 y clipping 금지; sample grid 고정 시 N 변경에 따라 RMS 재계산. x<=1 거부. 실험 종료 시 명시적 공식과 RH가 다른 사실을 확인한다.

## 10-A Hypothesis Laboratory (model)
입력 β∈[.5,.95] step .005(default .75), γ=14.13472514173469 기본 고정(선택 다른 실제 높이 가능), log10 x=2…16. 참조 β=.5와 선택한 가상 켤레쌍 진폭 A=2exp(β ln x)/hypot(β,γ), 비율, √x ln²x로 정규화한 규모. log-log 축 y=log10 A, 기울기 β를 직접 표시. 대칭 quartet 탭: W(β)+W(1−β)로 계산한 모형을 표시, β=.5 겹침에서 한 쌍만 계산. 기본은 단일 쌍 비교이며 네 점의 결과와 혼용하지 않는다. x가 큰 영역에서 실제 π/ψ를 계산한 것처럼 표시하지 않는다. Big-O 상수 미지정, 1 초과는 위반 판정 아님. 검수: β=.5 비율=1, β=.9 및 x=10^12에서 정규화 규모 약 11.67(정확값은 oracle 계산), 대칭 유지, overflow/underflow 방지. 실제 ζ 결과와 독립된 모델 state.

## 11-A 논리 증명 조립 (model)
입력 4개 논리 퍼즐, 선택 가능한 근거 카드: 전제, 결론, 논리 규칙, 반례. 기본 "n>2인 소수→홀수", 역명제 반례 n=9. 추가: P∧Q→P, P→Q와 P에서 Q, P→Q와 Q에서 P의 오류. 정답/오답 각각 설명. 교육 논리 모형이며 Lean kernel을 실행하지 않음. 모든 카드 keyboard 선택, 드래그만 강제하지 않음.

## 11-B Mini Lean Playground (replay)
입력 퍼즐 선택, 현재 Goal State에서 후보 전술 선택 및 undo/reset. 후보 예제: P→P, P∧Q→Q∧P, a=b→b=a, 양수 전달, 0+n=n. 실제 pinned Lean/Mathlib 환경에서 성공 및 오류 입력을 실행하고 각 상태의 proof/goal/error를 fixture로 추출. 필요한 tactics intro, exact, rw, apply, constructor, cases 또는 simp. 각 선택에 맞는 다음 상태/오류, 성공 표시 '기록된 검증 결과'로 표기. 자유 입력·실시간 검사 UI 금지. 예제와 fixture가 실제 실행 로그에 일치해야 통과. 자세한 CI 절차 NUMERICS 및 PLAN 참고. 실제 실행되지 않은 예제는 pending 상태, 모방한 커널 메시지를 실측이라 하지 않는다.

## 11-C Dependency Explorer (model + reference)
입력 작은 Lean 예제 선택, depth 1…3, 노드 클릭. 정리의 명제, 직접 의존성, 전이적 관계와 공리. 교육용 논리 규칙 그래프와 실제 Lean 선언 참조 그래프 별도 탭. Lean Meta 또는 export에서 추출할 때 선언 이름, 원본 파일/커밋, extraction tool version, edge direction(정리→의존성)을 명시. 라이브러리 전체 그래프를 임의 생성하지 않음. 검수: fixture에 없는 간선 없음; direct/ transitive 구분; 순환·누락 처리; 미확인 상태 라벨.

## 12-A Proof Explorer (reference)
입력 판본 original / compact / readable(검증 자료 제공 범위에서), 목표 5개, 깊이/단계 필터, 검색. 기본 다섯 목표는 MIT 검증 기록과 정확한 선언 이름을 대응: riemannHypothesis, riemannZeta_eq_zero_re, LFunction_ne_zero_of_half_lt_re, LFunction_eq_zero_re, LFunction_eq_zero_re_of_isPrimitive. 원본 버전과 단축본의 정확한 소스 파일·라인·해시 별도. 노드 필수 필드 id, version, declaration, statement, plainExplanation, sourceUrl(commit permalink), evidenceType, checkerStatus, asOf, sourceCitation; edge 필드 from,to,kind(direct/transitive/conceptual), provenance. 실험 기능: 명제/논증 지도/검증 상태/원본 링크. 최상위 경로 교육적 도식은 실제 DAG가 아니라고 표시. 외부 읽기 프로젝트에만 있는 논증은 third-party 해설로 표시, 실제 의존성 확인 전 간선 등록 금지. 수백만 줄과 전체 Lean archive를 Pages에 포함하지 않음. 검수: 최소 다섯 목표는 원본 고정 commit에 연결, 검증 요약은 판본별 MIT 날짜와 근거, 모든 직접 간선은 추출 또는 수동 원문 확인 근거, 미확인 노드는 보류 목록에 남김. 정확한 데이터가 부족하면 허위 그래프 대신 검증된 범위만 제공.
