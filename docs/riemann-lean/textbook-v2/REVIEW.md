## 검토 3: 수학
- 1은 소수 아님; 유클리드의 Q 자체가 반드시 소수는 아님; 합성수 연속 예제 유효.
- π~x/ln x의 비율 의미와 절대오차 구별. 표준 li 및 Li₂의 하한 차이 반영.
- ζ의 급수/곱 Re(s)>1, eta Re(s)>0에서의 몫의 제거 가능한 분모 0, 진짜 극 s=1 구분. DLMF §25.2, §25.4, §25.10, §25.16, §25.18 확인.
- 영점의 좌우·켤레 대칭 및 실제/가상 분리. s=.5에서 반사 중복 제거. 임계선 수치 탐색으로 모든 영점의 완전성을 주장하지 않음.
- ψ=ln lcm, Λ(p^k)=ln p, 로그 미분의 k 약분, ψ₀ 점프 반쪽 규약 확인.
- 명시적 공식의 부호와 보정항, s=0 유수, 자명한 영점 기여, 켤레쌍 위상 및 진폭 확인. 페론 유도는 스케치라고 표시.
- RH ↔ 오차 정리와 단일 파동 분리. Big-O는 상수 C와 시작점 존재 조건이며 C=1 상한이 아님. β<1에서는 x^β/x→0.
- 실제/가상/절단/참조 데이터의 범주 라벨 규정.
- 원고의 역사 세부 및 전문 참고 문헌 식 번호는 출판 전 교차 확인 필요. 실제 전문가 감수는 미수행.

## 검토 4: 계산과 실험
EXPERIMENTS.md의 실험 헤더 25개를 원고 ID와 대조. 별도 Python mpmath/SymPy로 10개 count/weighted/log-integral 행, 60개 고정밀 영점 높이, 20개 explicit formula 값 계산. Node의 후보 zeta 함수를 고정밀 기준 404개 점과 비교: 404/404 pass, 허용 scaled error 1e−8, worst 7.71793e−11, worst absolute 3.60977e−10. 실제 pole/near-pole 응답 확인. 단순히 N을 크게 할 때 음의 실수부에서 상쇄가 악화됨을 확인하고 UI domain −2≤Re≤3, |Im|≤80 설정. 이 범위는 표본 검증 기반, 엄밀 오차 보증 아님. 60번째 영점은 높이 163.03이므로 direct evaluation 범위 밖인 것을 따로 표시. 기존 60개 높이는 더 정밀한 데이터로 교체 계획. 기존 구현 전체에 이 알고리즘을 통합·테스트하지는 않음. check-zeta.py는 검증에 사용한 절차를 재실행 가능한 스크립트로 묶은 것; 최종 통합에서 실행해야 함.
