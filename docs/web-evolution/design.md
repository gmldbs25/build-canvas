# Work 7 — The Evolution of the Web

Build Canvas에서 Work 7을 열면 짧은 소개와 1993년 웹을 여는 시작 버튼이 보인다. 체험 중에는 상단에서 시대를 오갈 수 있다. 선택한 연도로 반투명 강조 표시가 이동하고 장면이 부드럽게 바뀐다. 기기에서 동작 줄이기를 켜면 전환 없이 즉시 바뀐다. 시대별 브라우저 프레임이 화면 대부분을 차지하고, 영어로 된 웹사이트 바깥에 한국어 행동 안내와 도움말이 있다. 기존 `?era=1998&page=guestbook` 같은 장면 주소는 장면을 바로 연다.

## 장면

| 시대 | 웹사이트 | 방문자가 하는 일 |
| --- | --- | --- |
| 1993 · 문서 | Mosaic풍 브라우저의 초기 WWW 프로젝트와 별도 서버의 관측 메모 | 파란 링크를 따라가고 주소가 바뀐 것을 본 뒤 Back으로 돌아온다. |
| 1998 · 개인 홈페이지 | IE 4풍 브라우저의 The Orbit Room | 우주 관련 링크를 둘러보고 방명록에 서명한다. |
| 2005 · 사진 커뮤니티 | Firefox 1.5풍 브라우저의 Moonstream | 사진 아래의 `moon` 태그를 눌러 다른 여러 사람이 올린 사진을 찾는다. |
| 2013 · 웹앱 | Chrome 29풍 브라우저의 Fieldwork | 준비 카드를 옮기거나 편집한다. 카드 상태와 목록, 진행률, 활동 기록이 함께 바뀐다. |
| 2023 · AI 검색 | Google의 2023년 Search Generative Experience(SGE)를 참고한 Orbit Search | 관측회 정보를 검색하면 검색 중 화면, 차례로 나타나는 AI 답변, 일반 검색 결과를 경험한다. 답변의 출처나 검색 결과를 눌러 공지와 일정표를 확인한다. |
| 2025–26 · AI 에이전트 | 현대 브라우저의 관측소 웹사이트와 작업 패널 | 공지 비교와 카드 초안 작성을 맡긴다. 근거를 확인하고 승인하면 2013년 장면에서도 같은 카드를 볼 수 있다. |

브라우저 기능은 시대에 맞는 메뉴와 도구 모음으로 표시한다. 뒤로·앞으로, 주소 입력, 새로고침, 확대, 즐겨찾기와 탭을 각 시대에 맞게 제공한다. 새로고침을 누르면 현재 탭의 웹페이지 내용만 다시 그린다. 입력한 주소는 전시의 페이지 목록에서 찾는다. 여섯 장면은 이 작품을 위해 만든 웹사이트이며, 계정 없이 탐험할 수 있다.

방명록과 방문 횟수는 기기의 브라우저에 저장된다. 보드 상태, 탭과 즐겨찾기는 현재 방문 중 유지된다. AI 장면은 전시 안의 공지와 일정표를 사용해 검색과 에이전트 동작을 재연한다. Orbit Search는 전시 자료를 바탕으로 입력에 맞는 답변과 결과를 순서대로 보여 준다. 카드 반영은 방문자가 승인했을 때 실행된다.
